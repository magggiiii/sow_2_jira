<objective>
Make dedup actually merge. The baseline run did ZERO merges because Gemini Flash's single-shot JSON for 37+ pairs hit a mid-stream delimiter failure on both retry attempts. The agent silently gave up.

Fix (per D-34):
1. **Default batching**: send candidate pairs to the LLM in batches of 30.
2. **Adaptive halving**: on JSON parse failure (`ValueError` from `complete_json`), halve the batch size (floor 5) and retry the same window.
3. **Reconciliation pass**: after all batches complete, re-cluster the surviving tasks by embedding similarity, find any new candidate pairs above threshold (which appear because A+B merged → B dropped → C now neighbors A and might also merge), and run one more pair-decision pass. Cap at 2 reconciliation rounds.
4. **Audit visibility**: `DEDUP_BATCH` and `DEDUP_RECONCILE` audit actions so the run is debuggable.

Purpose: Land ≥ 20 merges on the same test_sow.pdf the baseline ran on (INT-02). Also: 12-01's json-repair fallback already de-risks parse failures, but batching is the structural fix — even with json-repair, smaller batches mean smaller blast radius for any one LLM hiccup.

Output: One agent file modified (3 helpers added, `deduplicate` rewired), one new pytest file.

This plan is INDEPENDENT of 12-01 (no file overlap, no functional dependency — json-repair just makes the path more robust, not necessary). Both run in Wave 1.

    def _apply_decisions(
        self,
        decisions: list[DedupDecision],
        task_map: dict[str, ManagedTask],
    ) -> set[str]:
        """
        Apply a batch of dedup decisions, mutating tasks in place via _merge_tasks.

        Returns the set of dropped task ids (so the caller can compose them across
        multiple batches and exclude them from the final result list).
        """
        drop_ids: set[str] = set()
        for decision in decisions:
            self.audit.log(
                run_id=self.run_id,
                agent="DeduplicationAgent",
                action=f"DEDUP_{decision.decision.upper()}",
                detail=f"{decision.task_id_a} vs {decision.task_id_b}: {decision.reason}",
            )

            if decision.decision == "merge":
                task_a = task_map.get(decision.task_id_a)
                task_b = task_map.get(decision.task_id_b)
                if task_a and task_b:
                    task_a = self._merge_tasks(task_a, task_b)
                    task_a.flags = list(set(task_a.flags))
                    drop_ids.add(decision.task_id_b)
                    task_b.status = TaskStatus.MERGED
                    task_b.merged_from = [task_a.id]

            elif decision.decision == "keep_first":
                drop_ids.add(decision.task_id_b)
                if decision.task_id_b in task_map:
                    task_map[decision.task_id_b].status = TaskStatus.MERGED

            elif decision.decision == "keep_second":
                drop_ids.add(decision.task_id_a)
                if decision.task_id_a in task_map:
                    task_map[decision.task_id_a].status = TaskStatus.MERGED

            # "keep_both" → no action

        return drop_ids

    4. Add `_run_batches`:

    ```python
    def _run_batches(
        self,
        candidate_pairs: list[tuple[ManagedTask, ManagedTask, float]],
        task_map: dict[str, ManagedTask],
    ) -> set[str]:
        """
        Send candidate_pairs to the LLM in adaptive batches.

        Strategy (D-34):
          - Default batch size: self.pair_batch_size (default 30).
          - On JSON parse failure (ValueError from complete_json), halve the
            CURRENT batch size (floor DEDUP_BATCH_MIN_SIZE) and retry the same
            slice. Once a batch succeeds, the next batch resets to the FULL
            batch size — failures don't permanently degrade throughput.
          - When the slice is at the floor and STILL fails, log DEDUP_BATCH_ABANDONED
            and move past it. Other batches proceed.

        Returns the union of dropped task ids across all batches.
        """
        all_drop_ids: set[str] = set()
        full_size = self.pair_batch_size
        i = 0
        total = len(candidate_pairs)
        batch_index = 0

        while i < total:
            batch_index += 1
            current_size = full_size
            slice_start = i
            slice_end = min(i + current_size, total)
            slice_pairs = candidate_pairs[slice_start:slice_end]

            attempt = 1
            succeeded = False
            while True:
                pairs_json = self._format_pairs_json(slice_pairs)
                self.audit.log(
                    run_id=self.run_id,
                    agent="DeduplicationAgent",
                    action="DEDUP_BATCH",
                    detail=(
                        f"batch={batch_index} attempt={attempt} "
                        f"size={len(slice_pairs)} "
                        f"range={slice_start}:{slice_start + len(slice_pairs)}"
                    ),
                )
                try:
                    raw_decisions = self.llm.complete_json(
                        prompt=DEDUP_PROMPT_TEMPLATE.format(pairs_json=pairs_json),
                        system=DEDUP_SYSTEM_PROMPT,
                        agent_name="DeduplicationAgent",
                    )
                    succeeded = True
                    break
                except (ValueError, RuntimeError) as e:
                    if len(slice_pairs) <= DEDUP_BATCH_MIN_SIZE:
                        self.audit.log(
                            run_id=self.run_id,
                            agent="DeduplicationAgent",
                            action="DEDUP_BATCH_ABANDONED",
                            detail=(
                                f"batch={batch_index} attempt={attempt} "
                                f"size={len(slice_pairs)} error={e}"
                            ),
                        )
                        break
                    # Halve and retry the SAME starting index with a smaller slice.
                    new_size = max(DEDUP_BATCH_MIN_SIZE, len(slice_pairs) // 2)
                    self.audit.log(
                        run_id=self.run_id,
                        agent="DeduplicationAgent",
                        action="DEDUP_BATCH_HALVE",
                        detail=(
                            f"batch={batch_index} attempt={attempt} "
                            f"old_size={len(slice_pairs)} new_size={new_size} error={e}"
                        ),
                    )
                    slice_end = min(slice_start + new_size, total)
                    slice_pairs = candidate_pairs[slice_start:slice_end]
                    attempt += 1

            if succeeded and isinstance(raw_decisions, list):
                decisions = [DedupDecision(**d) for d in raw_decisions if isinstance(d, dict)]
                drop_ids = self._apply_decisions(decisions, task_map)
                all_drop_ids |= drop_ids

            # Advance past whatever range we just attempted (success OR abandon).
            i = slice_start + len(slice_pairs)

        return all_drop_ids

    def _format_pairs_json(
        self, pairs: list[tuple[ManagedTask, ManagedTask, float]]
    ) -> str:
        return json.dumps([
            {
                "task_id_a": str(a.id),
                "title_a": a.title,
                "description_a": a.short_description,
                "task_id_b": str(b.id),
                "title_b": b.title,
                "description_b": b.short_description,
                "similarity_score": round(sim, 3),
            }
            for a, b, sim in pairs
        ], indent=2)
    ```

    ```python
    def _reconcile(
        self,
        surviving_tasks: list[ManagedTask],
        task_map: dict[str, ManagedTask],
        max_rounds: int = DEDUP_BATCH_MAX_RECONCILE_ROUNDS,
    ) -> set[str]:
        """
        After initial batched dedup, some merges may have created new candidate
        pairs among the survivors. Example: A+B merge → B dropped. If C was
        below threshold against B but now scores high against A, we missed
        a merge. Run up to `max_rounds` more passes of NN search + batched LLM
        confirmation on the survivors.

        Returns the union of additional dropped task ids across all rounds.
        """
        additional_drops: set[str] = set()
        embedder = self._get_embedder()

        for round_idx in range(1, max_rounds + 1):
            current_survivors = [t for t in surviving_tasks if str(t.id) not in additional_drops]
            if len(current_survivors) < 2:
                break

            texts = self._get_embedding_texts(current_survivors)
            embeddings = embedder.encode(texts, normalize_embeddings=True)

            new_pairs = self._find_candidate_pairs(current_survivors, embeddings)
            if not new_pairs:
                # Nothing left to reconcile — stop early.
                break

            self.audit.log(
                run_id=self.run_id,
                agent="DeduplicationAgent",
                action="DEDUP_RECONCILE",
                detail=f"round={round_idx} survivors={len(current_survivors)} new_pairs={len(new_pairs)}",
            )

            round_drops = self._run_batches(new_pairs, task_map)
            if not round_drops:
                # LLM said keep_both on every new pair — converged.
                break
            additional_drops |= round_drops

        return additional_drops
    ```
